Buying rules

How it finds stock

Speed (alerts + its own checks)

It uses the store's own small stock request when it can find one (a few KB, so it can check often), and the page otherwise. Hot mode halves these for a while after any sign of a drop; warm hours use three-quarters. It never goes under 1 second and backs off on its own if a store pushes back.

Alerts

Install the free ntfy app on your phone, tap +, and subscribe to this exact topic. Anyone who knows the name can read it, so keep it random.

Optional. Pushover's emergency alerts keep ringing until you acknowledge them, even overnight.

Set this to Chrome Remote Desktop and tapping a CAPTCHA or code alert on your phone opens this PC, so you can solve it from anywhere in seconds.

Discord restock channels

Open the restock server's PS5 channel in Chrome, copy the address bar link, and paste it here. At Start it opens in the watcher window; sign in to Discord there once. It only reads new posts.

Outside alerts (ntfy)

Anything posted to this topic, like a forwarded HotStock alert ("PS5 Pro in stock at Target"), makes it check that store immediately and go hot. It never buys from an alert alone. Use a different topic from the one above.
